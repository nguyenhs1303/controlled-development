# Convention code

Hiệu chỉnh file này từ formatter, linter, code hiện có và quy định của đội dự án.

- Nêu naming, layering, dependency direction và pattern bắt buộc.
- Nêu quy tắc logging, validation, error handling và API documentation.
- Nêu giới hạn file/method hoặc complexity nếu có.
- Nêu convention test và fixture.
- Không dùng vi phạm cũ làm mẫu để sao chép.
- Không mass-retrofit style hoặc comment ngoài phạm vi thay đổi.
