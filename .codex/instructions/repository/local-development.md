# Phát triển local

<!-- REPOSITORY-BOOTSTRAP-PENDING -->

Hiệu chỉnh file này theo repository:

- Prerequisite và phiên bản runtime/toolchain.
- Lệnh cài dependency, build, test, lint và chạy local.
- Cách dùng service phụ trợ hoặc container.
- Port, health check và smoke test an toàn.
- Hạn chế khi thiếu VPN, registry, artifact repository hoặc credential.
- Cách truyền secret bằng biến môi trường hoặc secret store mà không sửa file chứa secret.

Không tuyên bố runtime đã pass nếu chưa quan sát tín hiệu khởi động thành công và gọi được check phù hợp.
