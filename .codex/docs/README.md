# Tài liệu do Codex quản lý

- `source/`: tài liệu đầu vào và hợp đồng của repository.
- `specs/`: đặc tả thay đổi đã viết hoặc phê duyệt.
- `plans/`: kế hoạch kỹ thuật.
- `api/`: API contract theo implementation.
- `sql/`: ghi chú SQL, DDL hoặc execution plan.
- `runbooks/`: hướng dẫn build, chạy, vận hành và xử lý sự cố.

Không copy nội dung các thư mục này từ repository không liên quan.
